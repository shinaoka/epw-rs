# 等方的 Eliashberg 方程式と IR 基底：作業記録

作成日：2026-10-15．[sparse_ir_analysis_ja.md](sparse_ir_analysis_ja.md) §7 の段階 1〜3（等方的）の実装記録です．

## 結果

- **段階 1 と 2（一様格子，EPW と比較）：** MgB₂ の `MgB2.a2f` と `MgB2.dos` を入力に，FSR と FBW の方程式を解きました．EPW を `conv_thr_iaxis = 1e-12` で解いた結果と，すべての松原点で Z，Δ，χ が相対 5e-11 以内で一致します（15 K と 20 K）．FSR の自由エネルギーと McMillan の Tc も，印字された桁で一致します．
- **段階 3（IR，feature `sparse-ir`）：** EPW には等方的な IR ソルバーがないので，次の 3 つで検証しました．
  - **厳密な和：** Σ_m 1/(ω_m² + a²) = tanh(a/2T)/(2aT) と相対 6e-13 で一致．
  - **密な一様和：** Einstein 型の核との畳み込みが，最大値に対して 1e-10 以内で一致．
  - **τ 点の範囲：** sparse-ir-rs の既定（[−β/2, β/2]）と (0, β) に写した点で，結果が完全に同じ．
- **MgB₂ の FBW（15 K）：** 打ち切りを広げた一様格子の解が，IR の解に単調に近づきます．

| 方法 | 松原点 | Δ(iω₀) (meV) | IR との差 |
|---|---|---|---|
| IR（Λ = 1e5，ε = 1e-10） | 48 | 5.045696 | — |
| IR（Λ = 1e6，ε = 1e-6） | 37 | 5.045697 | 1e-7 |
| IR（Λ = 1e5，ε = 1e-6，EPW と同じ） | 31 | 5.045571 | 2.5e-5 |

FBW では μ* の項と χ が帯域幅（約 20 eV）まで寄与するので，`wscut = 0.5 eV` では Δ が 7% 小さく出ます．IR は 31〜48 点で打ち切りのない値を与えます．

## 設計

- **`eliashberg` クレート：** EPW を知らない基盤クレートです．入力は α²F と（FBW では）DOS だけで，エネルギーは eV，温度は k_B T（eV）です．EPW の形式の読み込みは `eph-io-epw::supercond` にあります．
- **振動数の和の trait（`FrequencySum`）：** 方程式本体は和の取り方を知りません．
  - `UniformSum`：`wscut` 以下のすべての点．EPW の `gridsamp = 0` と同じです．
  - `IrSum`：IR 基底．Cargo feature `sparse-ir` で有効になります．
  - 和は Σ_{m∈ℤ} λ(n−m) f(m) として定義し，f の偶奇（`Parity`）を渡します．一様格子では K± = λ(n−m) ± λ(n+m+1) の行列と einsum で計算します（Pickett の式 4.4 と同じ形）．
- **IR の計算方法：**
  - 奇関数を i f，偶関数を f として正の松原点で fit します．実係数になるので `MatsubaraSamplingPositiveOnly` を使います．
  - τ 点で評価し，λ(τ)/T と掛けて τ で fit し，松原点で評価します．
  - fit と evaluate は行（関数）を軸にしたバッチの nd 演算です．
- **τ = 0⁺：** μ* の項の Σ_m f(m) は，係数と u_l(0⁺)（`evaluate_tau(&[0.0])`）の内積から厳密に取ります．EPW の fork のように「最初の正の τ 点」で代用することはしていません．
- **sparse-ir-rs：** crates.io の `sparse-ir` 0.13.0 を使います．これは tenferro-tensor 0.7.1 の `TypedTensor` の上に作られているので，epw-rs のテンソルをそのまま渡せます．
- **SVE の費用：** SVE は温度によらず 1 回だけ（`IrBasisSet`）です．費用は ε に強く依存します．Λ = 1e5 で ε = 1e-6 なら 0.24 秒，ε = 1e-10 では 29 秒かかります．畳み込み 1 回は 0.3 ms です．
- **自己無撞着ループ：** 線形混合で，収束判定は Σ|ΔΔ|/Σ|Δ| です．固定点は混合法によらないので，EPW と比べるときは両方とも厳しい閾値まで収束させます．EPW の Broyden 混合は再現していません．

## 見つかった点

1. **EPW の `fila2f` 実行のゼロ除算（EPW への報告候補）：** `supercond.f90:104` は Fortran で短絡評価されないので，`fila2f` を指定していても `MOD(nkf1, nqf1)` を評価します．メッシュを入力に書かないと，整数のゼロ除算で止まります．`crystal.fmt` も必要です．
2. **EPW の FBW の自由エネルギー：** EPW の値は，FSR の Bardeen–Stephen の式で Z_N を「π なし」（`1 + T Σ K⁻/ω`）にしたものと一致します．FSR の Z_N は πT です．π を付けると 20 K で正になります．FSR の式を FBW にそのまま使うこと自体が近似（χ とエネルギー積分を無視）なので，どちらが正しいかは判断していません．
3. **IR の精度：** EPW と同じ ε = 1e-6 の基底では，MgB₂ の Δ に相対 2.5e-5 程度の誤差が出ます．EPW の `eps_cut_ir`（係数の切り捨て）は実装していません．
