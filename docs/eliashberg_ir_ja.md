# Eliashberg 方程式と IR 基底：作業記録

作成日：2026-10-15．[sparse_ir_analysis_ja.md](sparse_ir_analysis_ja.md) §7 の段階 1〜4（等方的と異方的）の実装記録です．

## 結果

- **段階 1 と 2（一様格子，EPW と比較）：** MgB₂ の `MgB2.a2f` と `MgB2.dos` を入力に，FSR と FBW の方程式を解きました．EPW を `conv_thr_iaxis = 1e-12` で解いた結果と，すべての松原点で Z，Δ，χ が相対 5e-11 以内で一致します（15 K と 20 K）．FSR の自由エネルギーと McMillan の Tc も，印字された桁で一致します．
- **段階 3（IR，feature `sparse-ir`）：** EPW には等方的な IR ソルバーがないので，次の 3 つで検証しました．
  - **厳密な和：** Σ_m 1/(ω_m² + a²) = tanh(a/2T)/(2aT) と相対 6e-13 で一致．
  - **密な一様和：** Einstein 型の核との畳み込みが，最大値に対して 1e-10 以内で一致．
  - **τ 点の範囲：** sparse-ir-rs の既定（[−β/2, β/2]）と (0, β) に写した点で，結果が完全に同じ．
- **MgB₂ の FBW（15 K）：** 打ち切りを広げた一様格子の解が，IR の解に単調に近づきます．

| 方法 | 松原点 | Δ(iω₀) (meV) | IR との差 |
|---|---|---|---|
| IR（Λ = 1e5，ε = 1e-10） | 48 | 5.045696 | — |
| IR（Λ = 1e6，ε = 1e-6） | 37 | 5.045697 | 1e-7 |
| IR（Λ = 1e5，ε = 1e-6，EPW と同じ） | 31 | 5.045571 | 2.5e-5 |
| 一様，wscut = 0.5 eV（EPW の設定） | 62 | 4.693112 | 7.0e-2 |
| 一様，wscut = 2 eV | 246 | 4.800423 | 4.9e-2 |
| 一様，wscut = 8 eV | 985 | 4.950979 | 1.9e-2 |
| 一様，wscut = 32 eV | 3940 | 5.019707 | 5.2e-3 |

FBW では μ* の項と χ が帯域幅（約 20 eV）まで寄与するので，`wscut = 0.5 eV` では Δ が 7% 小さく出ます．IR は 31〜48 点で打ち切りのない値を与えます．

## 設計

- **`eliashberg` クレート：** EPW を知らない基盤クレートです．入力は α²F と（FBW では）DOS だけで，エネルギーは eV，温度は k_B T（eV）です．EPW の形式の読み込みは `eph-io-epw::supercond` にあります．
- **振動数の和の trait（`FrequencySum`）：** 方程式本体は和の取り方を知りません．
  - `UniformSum`：`wscut` 以下のすべての点．EPW の `gridsamp = 0` と同じです．
  - `IrSum`：IR 基底．Cargo feature `sparse-ir` で有効になります．
  - 和は Σ_{m∈ℤ} λ(n−m) f(m) として定義し，f の偶奇（`Parity`）を渡します．一様格子では K± = λ(n−m) ± λ(n+m+1) の行列と einsum で計算します（Pickett の式 4.4 と同じ形）．
- **IR の計算方法：**
  - 奇関数を i f，偶関数を f として正の松原点で fit します．実係数になるので `MatsubaraSamplingPositiveOnly` を使います．
  - τ 点で評価し，λ(τ)/T と掛けて τ で fit し，松原点で評価します．
  - fit と evaluate は行（関数）を軸にしたバッチの nd 演算です．
- **τ = 0⁺：** μ* の項の Σ_m f(m) は，係数と u_l(0⁺)（`evaluate_tau(&[0.0])`）の内積から厳密に取ります．EPW の fork のように「最初の正の τ 点」で代用することはしていません．
- **sparse-ir-rs：** crates.io の `sparse-ir` 0.13.0 を使います．これは tenferro-tensor 0.7.1 の `TypedTensor` の上に作られているので，epw-rs（tenferro-tensor 0.10.0）のテンソルは `ir.rs` の `to_ir`/`from_ir` で写してから渡します．sparse-ir が tenferro 0.10 に追随したら，この変換は消します．
- **SVE の費用：** SVE は温度によらず 1 回だけ（`IrBasisSet`）です．費用は ε に強く依存します．Λ = 1e5 で ε = 1e-6 なら 0.24 秒，ε = 1e-10 では 29 秒かかります．畳み込み 1 回は 0.3 ms です．
- **自己無撞着ループ：** 線形混合で，収束判定は Σ|ΔΔ|/Σ|Δ| です．固定点は混合法によらないので，EPW と比べるときは両方とも厳しい閾値まで収束させます．EPW の Broyden 混合は再現していません．

## 見つかった点

1. **EPW の `fila2f` 実行のゼロ除算（EPW への報告候補）：** `supercond.f90:104` は Fortran で短絡評価されないので，`fila2f` を指定していても `MOD(nkf1, nqf1)` を評価します．メッシュを入力に書かないと，整数のゼロ除算で止まります．`crystal.fmt` も必要です．
2. **EPW の FBW の自由エネルギー：** EPW の値は，FSR の Bardeen–Stephen の式で Z_N を「π なし」（`1 + T Σ K⁻/ω`）にしたものと一致します．FSR の Z_N は πT です．π を付けると 20 K で正になります．FSR の式を FBW にそのまま使うこと自体が近似（χ とエネルギー積分を無視）なので，どちらが正しいかは判断していません．
3. **IR の精度：** EPW と同じ ε = 1e-6 の基底では，MgB₂ の Δ に相対 2.5e-5 程度の誤差が出ます．EPW の `eps_cut_ir`（係数の切り捨て）は実装していません．

## 異方的・FBW（段階 4）

- **入力：** EPW が `ephwrite` で書く `MgB2.ephmat/`（`freq`，`egnv`，`ikmap`，`npool`，`ephmat1`）と `selecq.fmt` を `eph-io-epw::ephmat` で読みます．EPW と同じ規則で Fermi 窓の状態と (k, q) の組を選び，ストリームを最後まで読み切ることを確かめています．MgB₂ では 28 個の k × 5 バンド = 140 状態です．
- **モデル：** `eph-driver::supercond` が EPW のデータを `AnisotropicModel` に変換します．
  - 状態の組の核 L_{ss'}(iν)：(k, q, モード, バンド) ごとの寄与 w_q |g|²/(2ω) を，k+q が同じ既約点に写る q について足したもの．
  - Coulomb の重み M_{ss'}．
  - Fermi 面の重み．
- **振動数の和：** 等方的と同じく trait（`StateFrequencySum`）にしています．
  - 一様格子：einsum `"sql,mq->slm"` のあとに添字を付け替えます．
  - IR：核を一度だけ τ に変換し，各 τ で einsum `"tsq,tq->ts"` を取ります．
- **EPW 側の参照値：** `epw6`/`epw7` の設定で収束判定を 1e-10 にして流し直しました．Broyden 混合（既定）は一様格子で 1e-5 前後から下がらなかったので，一様格子だけ線形混合（`broyden_beta = -0.3`）にしています．Rust 側は線形混合 0.3 で，どちらも 150 回程度で 1e-12 まで収束します．

| 比較（20 K と 30 K，140 状態 × 全松原点） | Z | Δ | χ | 自由エネルギー |
|---|---|---|---|---|
| 一様格子，EPW `epw6`（厳しい収束判定） | 2e-10 | 5e-10 | 1e-10 | 印字された桁で一致 |
| IR，EPW のファイルの点に固定，EPW `epw7` と比較 | 2e-6 | 1.1e-5 | 4e-6 | — |

差は最大値に対する比です．IR の差について：
- **最後の係数の扱い：** EPW の「基底サイズが奇数のとき最後の係数を足さない」扱い（[upstream_findings_ja.md](upstream_findings_ja.md) の 3）を再現すると，Δ の差は 1.6e-5 から 1.1e-5 に縮みます（オプション `epw_drop_last_coefficient`）．
- **残りの差：** 主に EPW の係数の切り捨て（`eps_cut_ir = 1e-5`）と，基底そのものの違い（Python で作ったファイルと sparse-ir-rs）によるもので，どちらも ε = 1e-6 程度です．切り捨ては EPW が (q, バンド) ごとの核にかけるので，状態の組ごとに核をまとめるこちらの構造では正確には再現できません．
- **既定の点との比較：** sparse-ir-rs の既定の点（τ 点は両端を含まない 61 点）を使うと，EPW との差はさらに小さくなりました（Fermi 面平均の Δ̄ で 2e-6）．

**IR と一様格子の比較（20 K）：** IR の Δ̄ は 14.312 meV，一様格子（`wscut = 0.5 eV`）は 13.857 meV で，3% 違います．等方的のときと同じく打ち切りの効果です．計算時間は IR が 2.7 秒（31 点），一様格子が 14 秒（46 点）です．

## EPW の IR の挙動の再現，Coulomb 項，Padé

### EPW の係数の切り捨て（`eps_cut_ir`）

- **再現の仕方：** EPW は IR 係数の切り捨てを次の 2 か所にかけています．
  - 核の行（状態 s，q，k+q 側のバンドごと）．
  - 常伝導の G の行．ωZ/Θ と ξ/Θ を 1 本の複素関数 −(iωZ + ξ)/Θ として切ります．
- **核の行：** `KernelEntry` に q の番号を持たせました．行ごとに fit，切り捨て，τ での評価を行い，そのあとで状態の組 [τ, s, s'] にまとめます．切り捨て後も τ 表示では線形なので，今の構造のまま再現できます．
- **G の行：** trait に `convolve_normal` を加えました．IR 版では 2 つの係数の和で共通の最大値を取って切ります．
- **設定：** `IrSettings`（旧 `SamplingPoints`）で指定します．サンプリング点，奇数サイズで最後の係数を落とす扱い（`epw_drop_last_coefficient`），切り捨て（`epw_coefficient_cut`）の 3 つです．
- **結果（20 K と 30 K，140 状態，最大値に対する比）：**

| 比較 | Z | Δ | χ |
|---|---|---|---|
| IR，3 つとも再現，EPW `epw7`（`eps_cut_ir = 1e-5`）と比較 | 1e-8 | 4e-9 | 1e-9 |
| IR，切り捨てなし，EPW（`eps_cut_ir = 0`）と比較 | 3e-10 | 5e-10 | 5e-10 |

  Python で作った基底のファイルと sparse-ir-rs の基底の違いは，結果にほとんど効きません．切り捨ての有無による差は 1e-5 程度です（自由エネルギーは −0.139385 と −0.139388 meV）．

### Coulomb 項（`icoulomb = 1`）

- **読み込み：** `nscf2supercond.x` の出力を `eph-io-epw::supercond::read_coulomb_bands` で読みます（格子，対称操作，バンド）．
- **状態の分類：** `eph-driver::supercond::coulomb_states` が EPW と同じ規則で行います．
  - エネルギー窓に入るバンドの範囲．
  - k 点の格子での対応と，対称操作による全格子への展開．
  - `nbnd_offset` の探索．
  - (バンド, 全格子の k) を Fermi 窓内の状態と窓外の状態に分ける．
- **MgB₂ の例：** 窓内のバンドは 8 本，ずれ 0，Wannier と nscf のエネルギー差の最大は 6.49 eV です（EPW の出力と同じ）．状態は窓内 1080 個，窓外 594 個です．
- **方程式：** μ* の項を K = (μ*/(N_F N_k)) Σ_j n_j Σ_m Δ_j Z_j/Θ_j に置き換えます．窓外の状態は Z = 1，χ = 0 で，共通のギャップ Δ_c = −T K を持ちます．IR では，窓外の状態の行にも EPW と同じ切り捨てをかけます．
- **結果（`epw8` を収束判定 1e-10 で流し直したものと比較）：** Z，Δ，χ は 3e-10 以内で，自由エネルギーも印字された桁まで一致します．窓外の状態のギャップは −5.05 meV（20 K）で，斥力によって符号が反転しています．

### Padé による実軸への解析接続

- **実装：** Vidberg–Serene の連分数（`Pade`）です．係数の再帰の演算の順序を EPW と揃えています．
- **規則：** 点の数，実軸の格子，ギャップの端の決め方は EPW と同じです．
  - 点の数：N = 90% × nsiw を偶数に丸めたもの．
  - 実軸の格子：ω_i = i·ω_max/500．
  - ギャップの端：Re Δ(ω) = ω となる点．
- **悪条件：** Padé は非常に条件が悪い問題です．松原点の入力に相対 1e-10 の乱れを加えたとき，出力がどれだけ動くかを測りました．

| T | 点 | N | ギャップの端の変化 | Δ(23 meV) の変化 |
|---|---|---|---|---|
| 20 K | 一様格子 | 42 | 0.045 meV | 3.4e-4 eV |
| 20 K | IR | 28 | 0.0013 meV | 1.3e-5 eV |
| 30 K | 一様格子 | 28 | 0.59 meV | 1.6e-3 eV |
| 30 K | IR | 28 | 0.0024 meV | 7.0e-6 eV |

  **IR のサンプリング点で作った Padé は，一様格子の点より 30〜250 倍安定です．** IR の点が低い振動数から高い振動数まで散らばっているためと考えられます．
- **EPW との比較：** 状態ごとの実軸の値は，どの実装でも入力の丸め程度の差で桁が揃わない量です．そこでテストでは同じ乱れで感度を測り，EPW との差がその 10 倍以内であることを確かめています．
  - IR 版は Δ(23 meV) が EPW と 1e-9 eV で一致し，ギャップの端の最小値・最大値も全桁一致しました．
  - 一様格子版のギャップの端の差は 0.0015 meV（20 K）と 0.04 meV（30 K）で，感度（0.045 meV，0.59 meV）の範囲内です．
