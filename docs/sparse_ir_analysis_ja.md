# EPW の sparse-ir（IR 基底）実装の分析と，Rust 版の方針

作成日：2026-10-15．QE 7.6（EPW 6.1）の upstream と，sparse-ir-rs を組み込んだ fork（`gitlab.com/h-m0r1/q-e_mine`，QE 7.4 ベース）のソースを読んだ結果です．行番号は QE 7.6 の `EPW/src` 以下です．

## 1. 要点

- **IR を使えるのは 1 つのソルバーだけです．** 異方的・全バンド幅（FBW）・虚軸の Eliashberg 方程式（`laniso`，`fbw`，`limag`，`gridsamp = 2`）です．等方的ソルバー（`supercond_iso.f90`）と，Fermi 面に制限した異方的ソルバーには IR のコードがありません（`supercond.f90:122-126` で止まります）．
- **upstream は IR 基底を計算せず，ファイルから読みます．** ファイルは Python の sparse-ir で作ったもので，`EPW/irobjs/ir_nlambda5_ndigit6.dat`（Λ = 1e5，ε = 1e-6）が同梱されています．作成スクリプト `dump.py` はツリーにありません．
- **fork はビルドオプション `QE_USE_LIBSPARSEIR` で，sparse-ir-rs を使って実行時に基底を作ります．** Λ = 10^`nlambda`，ε = 10^-`ndigit` を入力にし（既定 5 と 6），`filirobj` は無視します．Eliashberg のアルゴリズムは upstream と同じです．
- **テストは IR の結果を検査していません．** `epw_super/epw7`，`epw8` は IR の経路を通りますが，testcode が比べるのは λ，McMillan と Allen-Dynes の Tc，BCS のギャップ推定だけです（`extract-epw.sh:67-70`）．

## 2. 入力

| 変数 | 既定 | 意味 |
|---|---|---|
| `gridsamp` | 0 | 松原格子の種類．2 が sparse-ir |
| `filirobj` | なし | IR オブジェクトのファイル（upstream のみ） |
| `eps_cut_ir` | 1e-5 | IR 係数の雑音カット（最大値に対する比）．0 以下で無効 |
| `positive_matsu` | true | 正の松原振動数だけを使う |
| `icoulomb`，`emax_coulomb`，`emin_coulomb`，`filnscf_coul` | 0，±1e5 eV | `fsthick` の外の状態からの Coulomb 項（`gridsamp = 2` が必須） |
| `nlambda`，`ndigit` | 5，6 | fork のみ．upstream ではファイルの見出しから読む |

`wscut` は虚軸の和には効きません．松原点の数はサンプリング点の数（この例では 31）で決まります．実軸の Padé の格子には `wscut` が使われます．

## 3. IR オブジェクトのファイル形式（upstream）

`io/io_sparse_ir.f90:66-256` が list-directed で読みます．見出し行は読み飛ばします．

```
#version 1
#lambda 100000.0
#eps 1e-06
#singular_values      size（61），s(1..size)
# sampling times      ntau（63），x(1..ntau) ∈ [-1, 1]
# u                   u(t, l)：l が外側，t が内側
# sampling frequencies F   nfreq_f（62），奇数の整数 2n+1（対称）
# uhat F              re im：l が外側，n が内側
# sampling frequencies B   nfreq_b（61），偶数の整数 2m（対称，0 を含む）
# uhat B
# sampling poles      nomega，y ∈ [-1, 1]
# v                   DLR 用（ソルバーは使わない）
```

- **τ の点は両端 x = −1（τ = 0）と x = +1（τ = β）を含みます．** 基底の大きさ 61 に対して 63 点です．
- **β による変換（`set_beta`，`sparse_ir.f90:386-425`）：** τ = β(x+1)/2，U(τ) = √(2/β) u，Û = √β û．温度ごとに同じオブジェクトを `set_beta` で変換し，ファイルは最初に 1 回だけ読みます．
- **`positive_matsu = .true.` のとき：** 正の半分だけを使い，フェルミオン 31 点，ボソン 31 点（ν = 0 を含む）になります．IR 係数は実数として fit します．

## 4. 方程式の実装（`sum_eliashberg_aniso_iaxis_fbw_ir`，`supercond_aniso.f90:2535-2997`）

1. 前の反復の Z，Δ，χ から，IR の松原点で次の 3 つを作ります．
   - G = −(iωZ + ε − μ + χ)/Θ
   - F = −ΔZ/Θ
   - G₀ = −iωZ/Θ₀（常伝導の Z 用）
   - Θ = (ωZ)² + (ε − μ + χ)² + (ΔZ)²，Θ₀ は Θ から Δ の項を除いたもの
2. ボソン側の核は K(iν) = 2 Σ_ν g² ω_qν/(ω_qν² + ν²) です．
3. 畳み込みは τ 空間で取ります．
   - 松原点から fit して IR 係数にし，τ 点で評価します．
   - cv(τ) = G(τ)·K(τ)/T を作り，τ で fit してフェルミオンの松原点で評価します．
   - これで cv(iω_n) = Σ_m G(iω_m) K(iω_n − iω_m) を，振動数の打ち切りなしで計算しています．
4. μ* の項は −μ* Σ_n ΔZ/Θ（全振動数）を F(τ = 0) から取ります．τ 点の 1 番目（x = −1，つまり厳密に τ = 0⁺）を使います．
   - 一様格子のソルバーは `wscut` で打ち切るので，IR 版とは定義が違います．
5. Z = 1 + T Σ/ω，Δ = T Σ_Δ/Z，χ = −T Σ_χ のように更新します．混合は (バンド, k) ごとに Broyden（または線形）です．
6. 収束判定は，31 点での Δ̄ の変化の単純和です．自由エネルギーも，サンプリング点での単純和です．

引用されている論文は Mori, Nomoto, Arita, Margine, PRB 110, 064505 (2024) と Wallerberger et al., SoftwareX 21, 101266 (2023) です．FBW の方程式は Margine & Giustino, PRB 87, 024505 (2013) にあります．

## 5. 注意すべき点

1. **τ の範囲と符号．**
   - upstream の点は [0, β]（両端を含む）です．既定の τ 点は，Julia と Python の sparse-ir では (0, β)，Rust の sparse-ir-rs では [−β/2, β/2]（偶数個）です．
   - sparse-ir は τ ∈ [−β, β] で評価でき，τ < 0 ではフェルミオンなら G(τ) = −G(τ+β) という反周期的な延長の値を返します（[sparse-ir の規約](https://spm-lab.github.io/sparse-ir-doc/src/notation.html)）．
   - 同じ τ での積 G(τ)K(τ)（フェルミオン × ボソン）は，どちらの範囲でも整合します．
   - **符号が変わり得るのは，G(0⁺) を使う項（μ*，`muchem`）と，G(−τ) や G(β−τ) を使う項です．** 0⁺ と 0⁻ では G(0⁺) − G(0⁻) = −1 だけ跳ぶので，区別が要ります．
2. **fork の μ* の項は近似になっています．**
   - sparse-ir-rs の既定の τ 点は端点を含まないので，fork は「最初の正の点」（添字 `ntau_f/2 + 1`）を 0⁺ の代わりに使っています．upstream は厳密な 0⁺ です．
   - Rust 版では，基底関数を τ = +0 で評価して厳密な F(0⁺) を取ります．
3. **upstream の奇数サイズの扱い（EPW への報告候補）．** `evaluate_matsubara_f/b` は偶奇で列を分けるときに `n/2` を使います．そのため size = 61 のとき最後の係数（l = 60）が足されません（`sparse_ir.f90:682-684` など）．影響は ε 程度と見込まれますが，測っていません．
4. **IR 係数を 0 にする hack（`eps_cut_ir`，既定 1e-5 で有効）．**
   - 自己無撞着ループの毎回，行（状態）ごとに |c_l| / max_l |c_l| < `eps_cut_ir` の係数を 0 にします．係数は l とともに減衰するので，実質的には高次の係数を落とします（`supercond_aniso.f90:2826-2858`）．
   - ループが `jx2 = 1..jx` なので，切られるのは G の常伝導の行と核 K だけです．F（異常項）と G₀ の行（オフセット `siz_ir`，`2*siz_ir`）は切られません．オフセットの付け忘れの可能性があります．fork も同じです．
   - Rust 版では，同じ処理を「行ごとの相対カット」としてオプションにします．EPW と比べるときは，EPW と同じ行にだけかけるモードも用意します．
5. **サンプリング点はバージョンで変わります．**
   - sparse-ir の版によって点の位置（さらに範囲の規約）が変わります．EPW と比べるときは EPW のファイルの点に固定します．
   - 基底関数そのものの違いは ε 程度なので，同じ点を使えばサンプリング点上の値は ε 程度で一致するはずです．ビット単位の一致は狙いません．
6. **17 K の収束は不安定です．** `epw7` の 17 K は 53 回の反復で振動しており，`conv_thr_iaxis = 1e-2` も緩いので，厳密な一致は期待できません．比較は 20 K と 30 K で行います．

## 7. Rust 版の方針

**オプションにする方法：**
- `eliashberg` クレートに Cargo の feature `sparse-ir` を設けます．振動数の和は trait にし，一様格子の実装を既定，IR の実装を feature で有効にします．
- IR の実装は sparse-ir-rs（crates.io の `sparse-ir`）で基底を作ります．サンプリング点は 2 通りから選べるようにします．
  - sparse-ir-rs の既定の点．
  - EPW の IR オブジェクトのファイルから読んだ点（EPW との比較用）．
- fit と evaluate は，状態（バンド，k）をバッチの軸にして nd 演算でまとめて行います．1 本ずつは呼びません．
- τ = 0⁺ の値は，サンプリング点で代用せず，基底関数を τ = +0 で評価して取ります．
- 境界データの読み込みと方程式の本体は，feature によらず共通にします．

**検証の方法：** IR の結果は，多数の点を使った密な一様サンプリング（打ち切りを十分大きくした極限）と比べます．EPW との比較は一様格子の版で行い，IR の版は EPW のファイルの点に固定して `epw7` とも比べます．

**段階：**
1. **等方的・虚軸（一様格子）：** `.a2f` だけを入力にし，EPW の `epw_super` の等方的ステップと比べます．
2. **等方的・IR（feature）：** 1 を密なサンプリングにしたものと比べます．sparse-ir-rs を使う最小例です．
3. **異方的・FBW・虚軸（一様格子）：** `.ephmat` などの読み込みが必要です．`epw6` と比べます．
4. **異方的・FBW・IR（feature）：** 3 の密なサンプリングと比べ，さらに EPW のファイルの点に固定して `epw7` と比べます．`icoulomb`（`epw8`）は後回しにします．

fixture は QE 7.6 で `epw_super` を流して作ります（`ph.x` を含む）．Pb と同じく，出所と原著者を README に記録します．

**状況（2026-10-15）：** 段階 1〜3（等方的）を実装しました．FSR と FBW は EPW と相対 5e-11 で一致し，IR 版は厳密な和と密な一様和で検証しました（[eliashberg_ir_ja.md](eliashberg_ir_ja.md)）．IR は FBW でだけ使えるので，等方的でも FBW の方程式を使っています（FSR の被和関数は |ω| → ∞ で減衰しません）．
